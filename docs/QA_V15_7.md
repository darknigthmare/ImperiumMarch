## Réception visuelle et corrections

Les [14 vues Vesper](QA_PAINTED_VESPER.md), [huit vues MI09](validation/painted-route-v0157/receipt.json) et [huit vues MI13](QA_PAINTED_FOUNDRY_SITES.md) ont été examinées. Les PNG originaux restent inchangés.

L’audit croisé des reçus recoupe les sources actuelles, les 13 PNG sélectionnés et les 30 captures. Les états JSON Vesper possèdent leurs empreintes de fichier ; les états MI09 sont comparés selon le JSON compact du générateur. Les six états MI13 concordent avec les temps et faits consignés ; leur reçu ne déclare pas d’empreinte distincte de chaque fichier d’état. Cette différence de format est conservée explicitement.

Les pilotes MI09 et MI13 finissent leur sortie. MI09 conserve quatre migrateurs arrivés et le camion arrivé. MI13 conserve PT03 acquis. Les neuf scènes publiques Vesper reçoivent les opérations montrées, sans revendiquer une campagne Vesper entièrement jouée. Le contexte initial MI04 est configuré et déclaré dans son reçu.

## Octets de l’édition autonome locale

| Fichier | Octets | SHA-256 |
| --- | ---: | --- |
| HTML | 170 475 459 | `ecf7eb97d83481c9dc1661f55017ef0d1f0b0a3f42980af98415db4941ab5b94` |
| ZIP | 125 016 849 | `87b79009d6c1b57865954bcdae67524f7a6b68459e9b51226634b47dae470817` |

Le CRC32 de l’HTML est `4818945a`. Le [reçu Python indépendant](validation/v0157-offline-verification.json) confirme une seule entrée, sa date fixe et son identité octet pour octet après extraction. Le build local utilise Node 24.22.1 et zlib `1.3.2.1-motley-285e94b`. La CI et la publication utilisent Node 22 ; le workflow exige le même HTML, et enregistre les empreintes réelles du ZIP reconstruit sur son runner. Une différence de compression entre versions de zlib ne permet pas une différence de contenu extrait.

## Navigateur et publication

Le [rapport navigateur](QA_BROWSER_V15_7.md) décrit les tentatives et leur résultat réel. Les contrôles statiques, Canvas et du DOM modélisé ci-dessus ne prouvent ni le layout CSS dans un navigateur, ni une interaction native, ni le son, ni le matériel tactile, ni un essai humain. Aucun de ces niveaux n’est assimilé à un autre.

Le [suivi de publication](DEPLOYMENT.md) doit rattacher la CI distante, le commit fusionné, la Release et le déploiement Vercel effectivement observés. La disponibilité d’une construction locale ne suffit pas à les déclarer accomplis.
